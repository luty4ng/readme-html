  1. Install the extension
    Open chrome://extensions, enable Developer mode, and load this project's extension folder.
  2. Commit the document and link
    Put the UTF-8 HTML file and the link ending in #html-preview in the same public repository. Keep the link in its own paragraph.
  3. Refresh the GitHub README
    The extension loads the document below the link. Refresh open GitHub pages after reloading the extension too.

Prompt an AI for a compatible document: “Generate a single UTF-8 HTML file with inline CSS and SVG or CSS charts. Do not use JavaScript, external fonts, images, or stylesheets.”

How a marker becomes a preview

This is the extension's current loading and rendering workflow. No GitHub Pages site is required.

Step 1Find README markers

Find HTML file links ending in #html-preview.

Step 2Validate the repository and URL

Accept HTML files from the current repository; reject cross-repository and external URLs.

Step 3Fetch the HTML source

Read the public file from GitHub Raw without sending login credentials.

Step 4Render in an isolated area

Keep static layouts; block scripts, external resources, and form submissions.

A separate space for each document

A sandboxed iframe and content security policy restrict document behavior. The extension preserves GitHub's security policy and does not run repository JavaScript in the GitHub page. Preview text can still be misleading; check its source.

Frequently asked questions

Click a question to expand its answer. These panels use the browser's native HTML disclosure controls.

Why do I only see a link after installing?

Refresh GitHub first. Check that the extension is enabled, the page is a public repository README, the link ends in #html-preview, and the HTML file is in the same repository.

Can I embed any website in a README?

The current version only reads .html or .htm files from the same repository. External websites and cross-repository links are not supported.

What do readers without the extension see?

They see the ordinary GitHub file link. They can still inspect or download the HTML source; GitHub does not render the file inside the README by default.

Why are my images, fonts, or charts missing?

This release blocks external resources and JavaScript. Use inline CSS, inline SVG, or base64 raster images. Replace script-based charts with static SVG or CSS charts.

Does the preview automatically fit the whole document?

It uses a scrollable area with a fixed initial height. Drag the preview's lower edge to resize it, or scroll inside. Automatic document-height measurement is not implemented.

Does the extension collect usage data or upload documents?

It has no analytics, accounts, storage, or third-party preview service. Documents are read from GitHub Raw into browser memory; GitHub and network providers still receive the file requests.
