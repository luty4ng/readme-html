一个标记如何变成预览

以下是插件当前实现的读取与展示流程，无需创建 GitHub Pages 站点。

步骤 1识别 README 标记

找到以 #html-preview 结尾的 HTML 文件链接。

步骤 2核对仓库与地址

只接受当前仓库的 HTML 文件，拒绝跨仓库和外部地址。

步骤 3读取原始 HTML

通过 GitHub Raw 获取公开文件，不携带登录凭据。

步骤 4在隔离区域展示

保留静态布局，禁用脚本、外部资源和表单提交。

文档拥有自己的隔离区域

沙箱 iframe 与内容安全策略限制文档行为。插件不修改 GitHub 的安全策略，也不在 GitHub 页面中运行仓库里的 JavaScript。预览内容仍可能包含误导性文字，请自行判断来源。

常见问题

点击下方问题展开答案。这部分使用浏览器原生 HTML 折叠功能。

为什么安装后只看到链接，没有预览？

先刷新 GitHub 页面。确认插件已启用，页面是公开仓库的 README，链接以 #html-preview 结尾，并且目标 HTML 文件与 README 在同一个仓库里。

可以直接把任意网站嵌进 README 吗？

当前版本只读取同一仓库的 .html 或 .htm 文件。外部网站链接和跨仓库链接不属于支持范围。

没有安装插件的读者会看到什么？

会看到普通的 GitHub 文件链接。HTML 文件依然可以查看源码或下载；GitHub 默认不会把这个文件在 README 中渲染出来。

为什么原来的图片、字体或图表不见了？

首版禁用外部资源和 JavaScript。请使用内联 CSS、内联 SVG 或 base64 栅格图片；需要脚本运行的图表请改为静态 SVG 或 CSS 图表。

预览高度能自动适应整份文档吗？

当前使用固定高度的滚动区域。可以拖动预览底部调整高度，或在预览内部滚动；首版没有自动测量文档高度。

插件会收集使用数据或上传文档吗？

当前版本没有统计、账户、存储或第三方预览服务。文档直接从 GitHub Raw 读取到浏览器内存中，GitHub 和网络服务方仍能看到该文件请求。
