# GitHub README HTML preview demo

This demo shows how [README HTML](../README.md) renders same-repository static HTML reports inside a GitHub README. [Install the Chrome extension](../README.md#quick-start), open this page on GitHub, and refresh it if it was already open. The three marked links below should each display an inline preview. The full project overview is available in matching English and Simplified Chinese editions, with the same layout, charts, and FAQ.

The previews use inline CSS and SVG with no JavaScript or external assets. Their charts and metrics are sample data, not product usage or performance claims. Without the extension, the links remain ordinary GitHub file links.
